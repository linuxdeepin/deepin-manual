# Bibliotecas de aplicativos comuns|common-application-libraries|

Bem-vindo ao UOS Desktop V25! O sistema oferece compatibilidade com mais de **100.000** aplicativos populares disponíveis para download. Consulte a lista abaixo e procure os aplicativos na **Loja de Aplicativos** do sistema ou nos canais oficiais dos respectivos fornecedores.
